## 💡 Sobre o Projeto
Agente de Inteligência Artificial voltado para a área de nutrição, desenvolvido com foco em segurança de dados e fundamentação técnica através de curadoria documental.

### ⚙️ Como Funciona:
- **Coleta de Dados:** O usuário insere informações essenciais como nome, peso e idade.
- **Arquitetura RAG (Retrieval-Augmented Generation):** A IA não responde apenas com base no conhecimento geral, ela realiza uma busca em uma base de
- documentos técnicos rigorosamente curados.
- **Orientação Personalizada:** Utiliza Large Models (LLMs) para cruzar os dados antropométricos do usuário com a curadoria documental, gerando diretrizes e abordagens de dieta seguras.
